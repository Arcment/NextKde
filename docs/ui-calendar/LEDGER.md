## 外推待确认 (live only)
- **A STRICT MUTUAL-EXCLUSION CLAIM IS PROVED BY THE BLANK FRAME, NOT BY THE CLEAN FRAME (R130, load-bearing).** Measure two per-frame columns — the first control's ink and the *other* control's presence probe — and read the joint distribution: **never both** rules out a cross-fade, and **never neither** rules out a gap. Two exclusivity clauses (`L05`, and any "X hides while Y is open") cost one `nativeRecord` and one table. ⇒ **Look for the frame where both are ABSENT: that frame is the fingerprint of a sequential handoff, and its absence is the fingerprint of a cross-fade.**
- **A ROUNDED CAP BIASES A LEFT-EDGE SCAN RIGHT, AND THE BIAS GROWS AS THE CONTROL COLLAPSES (R130, load-bearing).** The field's radius is h/2 = 14, so a column-count threshold only fires where the cap has opened ⇒ the measured width reads **high** exactly when it matters (f51: 55 measured vs 39 from the curve). ⇒ **Measure a width at the control's PINNED edge or read it from `inspectGeometry`; never from a scan whose threshold interacts with the cap radius.**
- **`nativeRecord`'s `interval` IS A FLOOR, NOT A RATE (R130, load-bearing).** Requested 30 ms produced real spacings of **31–88 ms** (mean ~50) with no error and `saved:true` throughout; the request silently degrades to whatever `grabToImage` + save costs. ⇒ **Never place frames on a timeline by `index × interval`.** The true times are in the logged `[UIReview] native recording` JSON (`frames[i].elapsedMs`) — read that, then select frames by time. **Corollary: a 150 ms animation sampled at a nominal 30 ms may get only 2–3 points inside it, which is a *fit*, not a curve — say "consistent with", not "measured as".**
- **A POINTER CHANNEL IS PROVED BY A STATE CHANGE READ OFF GEOMETRY, NOT BY A FRAME (R129, load-bearing).** `pointerObject` + `inspectGeometry` on the same objectName pairs one synthetic click with a numeric before/after — 0 → 280 → 0 — which says more about "the click landed on THIS object" than any screenshot can. ⇒ **Before spending frames on a pointer clause, buy the channel for one `inspectGeometry` round-trip; it is free and it is falsifiable.**
- **A HARNESS TARGET STRING IS AN `objectName`, NOT AN `id` (R129, load-bearing).** `ReviewInput.cpp:25` `findChild<QQuickItem *>(name)` recurses by objectName ⇒ an `id` that differs from the objectName returns `found:false`, and `found:false` is indistinguishable from "no channel exists" unless you check the source. ⇒ **When a `pointerObject` probe reports not-found, grep the objectName before concluding the clause is unreachable.**
- **A BAND THAT GROWS BY MAX-ROW-COUNT IS PROVED BY ITS EMPTY COLUMN (R128, load-bearing).** ⇒ **Find the column with the fewest items; it is the only place the band's own edge is visible.**
- **A DECLARED PER-LEG ALPHA IS THE SECOND WITNESS TO R125 (R128, load-bearing).** `0.32` dark / `0.17` light at `:589` and 0.32 ≠ 1−0.17 ⇒ **never derive the dark leg from the light alpha.**
- **A GRADIENT-BEARING TOKEN IS PROVED BY ITS RAMP, NOT ITS MIDPOINT (R127, load-bearing).** ⇒ **When a token carries a gradient, measure ≥3 rows and fit the slope; one row is a coin flip.**
- **AN OPAQUENESS COMMENT IS A TESTABLE CLAIM (R127, load-bearing).** ⇒ **Read a designer's "on purpose" comment as a hypothesis, then test it.**
